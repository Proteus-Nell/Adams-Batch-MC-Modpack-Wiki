# `config/tensura/EliteTensura/RecordConfig.toml`

<small>[Elite Tensura](../index.md) &rsaquo; [Configs](index.md)</small>

## `[Records]`

| Option | Default | Range | Description |
|---|---|---|---|
| `bonusesEnabled` | true |  | Apply permanent stat bonuses from earned records. |
| `worldFirstBonusOnly` | false |  | Restrict record bonuses to world-first achievements only. When true, only a record's world-first claim holder receives its bonus, and records not flagged world-first grant no bonus to anyone. When false, every earner gets the bonus. |
| `voiceAnnouncementsEnabled` | true |  | Show a Voice of the World message when a record is earned. |
| `worldFirstAnnouncementsEnabled` | true |  | Broadcast a global Voice announcement when a world-first record is claimed. |
| `debug` | false |  | Log condition checks to the server log. |
