# Commands

<small>[Elite Tensura](../index.md)</small>

## Game rules

Change these with `/gamerule <name> <value>`.

| Game rule | Default | Description |
|---|---|---|
| `ETBlockPlayerToPlayerPlunder` | false | Block player-to-player skill plunder |
| `ETCalamityEnabled` | false | Enable World Calamity invasions |
| `ETForgeEnabled` | true | Enable Elite Tensura forge crafting |
| `ETMagiculeWorldSystem` | false | Enable the Magicule World system |
| `ETNationSpawnerSystem` | false | Gate player-placed spawners by nation level |
| `ETNationSystem` | false | Enable the nation system |
| `ETOuroborosProvideLoseSkill` | false | Ouroboros skill provide is a gift (giver loses the skill) instead of a copy |
| `ETPartySystem` | false |  |
| `ETPlayerNamingEpLoss` | false | Naming another player permanently transfers a share of your EP to them |
| `ETRecordsEnabled` | true | Enable Record progression |
| `ETSeasonSystem` | false | Enable the Season Chronicle system |
| `ETSkillProvideLoseSkill` | false | Skill provide is a gift (giver loses the skill) instead of a copy |
| `ETSubordinateEpShare` | false | Owners gain a share of nearby subordinates' kill EP |
| `ETSynergyRequireActiveTitle` | false | Title synergies only match active titles instead of all unlocked titles |
| `ETTitleSystem` | false | Enable the Elite Tensura title system |
| `ETWalpurgisEnabled` | false | Enable the Walpurgis council system |
