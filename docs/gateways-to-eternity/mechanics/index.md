# Mechanics

## Gate Pearls and Gateways

- A **Gate Pearl** summons a Gateway when you use it on a block. It won't work if the new Gateway would be too close to another one.
- Once open, the Gateway spawns its enemies wave by wave. Rewards pop out of the Gateway as you earn them.
- A Gateway **fails** (in a burst of lightning) if it can't spawn a mob, if a mob wanders too far away (outside the leash range), or if the wave timer runs out. Some Gateways have extra failure effects, such as explosions or summoning more enemies.

Every Gateway in the pack, with its waves, enemy boosts and rewards, is listed under [Gateways](../gateways/index.md).

## Gateway rules

Each Gateway can set these rules:

- spacing from other Gateways
- leash range and spawn range
- whether only player damage counts
- whether mobs are removed on failure
- whether a player must stay nearby
- whether it fails when a mob goes out of bounds
- whether mobs may change dimension or be discarded
