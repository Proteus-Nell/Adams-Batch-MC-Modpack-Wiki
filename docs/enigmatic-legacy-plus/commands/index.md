# Commands

<small>[EnigmaticLegacy+](../index.md)</small>

`<value>` is a required argument, `[value]` is optional. The permission column shows who can run it by default.

## `/cursetime`

| Syntax | Permission |
|---|---|
| `/cursetime get` | Owner (level 4) |

## `/cursetime get`

| Syntax | Permission |
|---|---|
| `/cursetime get <player>` | Owner (level 4) |
| `/cursetime get <player> <reverse>` | Owner (level 4) |

## `/cursetime set`

| Syntax | Permission |
|---|---|
| `/cursetime set <player> <ticks>` | Owner (level 4) |
| `/cursetime set <player> <ticks> <reverse>` | Owner (level 4) |
