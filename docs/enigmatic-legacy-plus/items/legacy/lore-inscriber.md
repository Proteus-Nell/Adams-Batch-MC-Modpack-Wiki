## Description

Right-Click to open GUI.

Insert ? to write formatted name and lore lines to it.

Blank Design Fragment

Use &amp;[0-f] to apply color formatting to any

following text in the name field.

Use &amp;[k/l/m/n/o/r] to apply font formatting.

Start the line with ! to add it as lore line,

or with ![0-99] to set the lore line with

specified index.

Enter -! or -![0-99] to remove the last lore

line added or lore line with specified index,

respectively.
