# Pack notes

Things that behave differently in **Adam's Batch** than in each mod on its own.

## Mod interactions in this pack

- **Artifacts + Relics:** the pack includes **RAR-Compat**, which turns every [Artifacts](artifacts/index.md) item into a Relics-style relic. Artifacts level up as you use them and unlock abilities, instead of the stock effects. Each artifact's page has an **In this pack** section with the relic abilities and their stats.
- **Tensura addons:** [TR: Nightmares](tr-nightmares/index.md), [Elite Tensura](elite-tensura/index.md), [TensuraMoreSkills](tensura-more-skills/index.md), [Tensura: Mysticism](tensura-mysticism/index.md) and [Ascension](ascension/index.md) all add to [Tensura: Reincarnated](tensura-reincarnated/index.md)'s skill and race pools, so reincarnation can roll skills and races from any of them.
