# `config/artifacts/client.toml`

<small>[Artifacts](../index.md) &rsaquo; [Configs](index.md)</small>

## Top level

| Option | Default | Range | Description |
|---|---|---|---|
| `showArtifactsOnPlayers` | true |  | Whether worn artifacts should be displayed on players<br>This config option is purely client-side, it does not change what other players see |
| `showFirstPersonGloves` | true |  | Whether models for gloves are shown in first person |
| `showTooltips` | true |  | Whether artifacts have tooltips explaining their effects |
| `useModdedMimicTextures` | true |  | Whether mimics can use textures from Quark |
| `enableCooldownOverlay` | true |  | Whether artifacts on cooldown should be displayed next to the hotbar |
| `cooldownOverlayOffset` | 10 |  | Location of the artifact cooldown gui element<br>Distance from the hotbar measured in pixels<br>Negative values place the element left of the hotbar |
| `heliumFlamingoOverlayOffset` | 0 |  | Controls the vertical position of the Helium Flamingo's charge meter |
