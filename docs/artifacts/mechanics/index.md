# Mechanics

> [!NOTE]
> **Pack note:** this pack includes **RAR-Compat**, so every artifact is also a **relic** that levels up and unlocks abilities. See the *In this pack* section on each artifact's page and the [Relics guide](../../relics/mechanics/index.md) for how levelling works.

## Finding artifacts

- **Chests:** artifacts appear in dungeon and structure chests. The `artifactRarity` config (**1**) scales how common they are (higher is rarer).
- **Campsites:** small underground camps between Y **-60** and **40**. A campsite has a **0.3** chance to hold a **Mimic** instead of a chest.
- **Mimics:** chest-shaped mobs that drop artifacts. See [Mobs](../mobs/index.md).
- **Mobs:** skeletons, zombies and piglins have a **0.0015** chance to spawn wearing an artifact.
- **Archaeology:** suspicious sand and gravel have a **0.0625** chance to contain one.

## Wearing artifacts

Artifacts go into Curios slots (head, necklace, belt, hands, feet and so on). Every artifact's page lists its slot and its config values from [`items.toml`](../configs/config-artifacts-items.md).
