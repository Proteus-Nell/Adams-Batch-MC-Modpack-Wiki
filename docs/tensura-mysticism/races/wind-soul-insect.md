## Evolution

- **Evolves from:** [Army Wasp Insectar](army-wasp-insectar.md), [Wasp](wasp.md)
- **Evolves into:** [Divine Army Wasp](divine-army-wasp.md)

- **On awakening (True Demon Lord / True Hero):** [Divine Army Wasp](divine-army-wasp.md)
