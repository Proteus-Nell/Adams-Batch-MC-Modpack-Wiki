## Evolution

- **Evolves from:** [Blue Centipede](blue-centipede.md)
- **Evolves into:** [Blue Centipede Savant](blue-centipede-savant.md), [Water Soul Insect](water-soul-insect.md)
- **Default evolution:** [Blue Centipede Savant](blue-centipede-savant.md)
- **On awakening (True Demon Lord / True Hero):** [Water Soul Insect](water-soul-insect.md)
