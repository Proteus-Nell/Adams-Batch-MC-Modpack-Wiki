## `[BrimstoneFlames]`

| Option | Default | Range | Description |
|---|---|---|---|
| `brimstoneFlamesDamage` | 15 |  | How much damage that the effect Brimstone Flames does each second per level. |
| `brimstoneFlamesBypassResistances` | true |  | Should Brimstone Flames bypass Resistances and degrade Nullifications? |
| `brimstoneFlamesBypassUSR` | true |  | Should Brimstone Flames cancel Ultraspeed Regeneration? |
| `brimstoneFlamesBypassIR` | true |  | Should Brimstone Flames cancel Infinite Regeneration? |
