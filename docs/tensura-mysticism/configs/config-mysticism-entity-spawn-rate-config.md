## `[SpawnChance]`

Spawn probability for mobs (1 in X chance). First value is Day, Second is Night.  
Examples: 1=100%, 5=20%, 10=10%. 0=disabled.

| Option | Default | Range | Description |
|---|---|---|---|
| `memoiresChance` | 1,000 |  | One of how many chances for Memoires to spawn. |
| `okamiChance` | 8 |  | One of how many chances for an Okami to spawn. |
| `shadowImpChange` | 10 |  | One of how many chances for a Shadow Imp to spawn. |
