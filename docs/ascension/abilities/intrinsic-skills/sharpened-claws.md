> Unarmed melee deals 10 damage (15 mastered).

## How it works

- Triggers on melee contact

## Obtaining

- Intrinsic skill of: [Kitsune](../../races/kitsune.md), [3 Tailed Fox](../../races/three-tail-fox.md), [6 Tailed Fox](../../races/six-tail-fox.md), [9 Tailed Fox](../../races/nine-tail-fox.md), [Divine Kitsune](../../races/divine-kitsune.md)

## Stats (config defaults)

Set in [`config/tensura/ascension-skills.toml`](../../configs/config-tensura-ascension-skills.md).

| Option | Default | Description |
|---|---|---|
| `sharpened_claws.enabled` | true | Enable Sharpened Claws. |
| `sharpened_claws.damageMastered` | 15 (0 to 1,000) | Unarmed damage while toggled, mastered. |
| `sharpened_claws.damage` | 10 (0 to 1,000) | Unarmed damage while toggled, unmastered. |
