## How it works

- Can be toggled on and off
- Activated by pressing the skill key

## Related

## Stats (config defaults)

Set in [`config/tensura/ascension-skills.toml`](../../configs/config-tensura-ascension-skills.md).

| Option | Default | Description |
|---|---|---|
| `angel_wings.enabled` | true | Enable Angel Wings. |
| `angel_wings.durationSeconds` | 60 (1 to 3,600) | Unmastered effect duration (seconds). |
| `angel_wings.cooldownSeconds` | 70 (0 to 3,600) | Unmastered cooldown (seconds). |
