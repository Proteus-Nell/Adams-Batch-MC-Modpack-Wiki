# Perks

<small>[Corail Tombstone](../index.md)</small>

Perks are upgrades bought with Knowledge of Death points. Open the perk screen from the Tombstone menu to spend them.

| Perk | Description | Improves |
|---|---|---|
| **Alchemist** | improves potions | potion duration |
| **Archaeologist** | chance of obtaining structures with the Lost Tablets | chance |
| **Channeler** | faster casting with magical items | casting speed |
| **Gladiator** | increases damages | additional damage dealt |
| **Glyphographer** | improves scrolls | scroll duration |
| **Guardian** | reduces received damages | less damage suffered |
| **Jailer** | improves Grave Key | chance to get an enchanted key on death, config chance_enchanted_grave_key is set to a value &lt;= 0 |
| **Memento Mori** | retains experience on death | experience, config xp_loss_on_death is set to 0 |
| **Necromancer** | improves Zombify and Pray of Undead | chance that controlled undead will become spellcasters, your alignment is above -1 |
| **Nightveiler** | can find sleep near creatures |  |
| **Priest** | chance for the Ankh of Prayer not to be on cooldown | chance after a prayer |
| **Resiliomancer** | improved stability with magical items | chance not being interrupted |
| **Rune Inscriber** | improves tablets and scrolls | chance to not consume a tablet use |
| **Scribe** | improves books | enchantments extracted |
| **Shadowalker** | improves stealth speed | speed |
| **Shadowveil** | reduces detection range of enemies | range |
| **Treasure Seeker** | increases the chances of finding special items | chance on the undead |
| **Witch Doctor** | improves Voodoo Poppet | chance to not be consumed on death prevention |
