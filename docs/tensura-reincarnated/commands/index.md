# Commands

<small>[Tensura: Reincarnated](../index.md)</small>

`<value>` is a required argument, `[value]` is optional. The permission column shows who can run it by default.

## Game rules

Change these with `/gamerule <name> <value>`.

| Game rule | Default | Description |
|---|---|---|
| `colossusRespawn` | false | Respawns the Elemental Colossus when a player who hasn't won against a colossus before reaches the arena in the Labyrinth |
| `demonLordAwaken` | 10,000 | The number of Soul Points needed to be a True Demon Lord |
| `demonLordSeed` | 200,000 | The amount of EP needed to be a Demon Lord Seed |
| `disableDaemonAutoMagic` | false | Disables daemons players from auto learn Aspectual Magics |
| `disableNullification` | false | Disables Nullification from being used |
| `disableSpiritualLimit` | false | Disables the ep limit that applies on spiritual players when entering a physical world |
| `epDeathPenalty` | 5 | The percentage of EP that the player will lose when respawning |
| `epGainMultiplier` | 1 | The multiplier of EP gain that an entity and its gear would get after defeating a target |
| `epSteal` | false | Enables certain skills to steal Energy (EP/MP/AP) from Players |
| `forceHarvestFestival` | 20,000 | The number of Souls needed to force the player into Harvest Festival for True Demon Lord |
| `hardcoreRace` | false | Makes some Races harder to play as |
| `labyrinthDeath` | false | Allows players to die in the Labyrinth Dimension instead of getting teleported out at 1HP |
| `labyrinthPvp` | true | Allows players to pvp in the Labyrinth Dimension |
| `maxApGain` | 1,000,000,000 | Maximum amount of Aura an entity can gain at once from killing a target |
| `maximumMagicExplosion` | 100 | The maximum radius in block that a Magic Explosion can grief the surrounding |
| `maxMpGain` | 1,000,000,000 | Maximum amount of Magicule an entity can gain at once from killing a target |
| `moddedEP` | 100 | How much percentage of default EP value that non-tensura modded mobs can be used for EP gain calculation |
| `mpSkillCost` | 100 | The percentage of MP that the player will lose when gaining a new skill |
| `noUniqueStart` | false | Starts with a buff in MP/AP but no Unique Skills |
| `npcGrief` | true | Allows Tensura humanoid NPCs to interact with the environment regardless of the Mob Griefing gamerule |
| `npcWorking` | true | Allows Tensura humanoid NPCs to do their profession/job like farming, chopping trees, fishing, etc. |
| `playerEP` | 100 | How much percentage of default EP value that fallen players can be used for EP gain calculation |
| `playerManualDodging` | false | Whether if players are allowed to use the keybind-based dodging feature |
| `playerMindControl` | true | Enables certain skills to mind control Players |
| `playerNaming` | true | Allows players to be named by others |
| `playerSummoning` | true | Allows players to be summoned by other Players |
| `resetCounterBonusUnique` | 0 | Gains more Unique skills on resetting based on how many Reset Counters per skill |
| `resetIncompletePenalty` | 0 | Number of points gets removed from the Reset Counter when a player uses any reset scroll while not meeting the requirement |
| `resetPerSkillLock` | 0 | Number of points of reset counter for each Unique Skill lock for the next reset |
| `rimuruMode` | false | Starts as Rimuru |
| `skillBeforeRace` | false | Gains Unique Skills before choosing race |
| `skillGriefing` | true | Allows Tensura Ability to grief the surrounding |
| `skillSteal` | true | Enables certain skills to steal Skills from Players instead of copying |
| `spawnerEP` | 10 | How much percentage of default EP value that mobs spawned from Spawners can be used for EP gain calculation |
| `tensuraDisplayName` | false | Displays the tensura name instead of minecraft name if the player is named |
| `tensuraEP` | 100 | How much percentage of default EP value that Tensura mobs can be used for EP gain calculation |
| `trulyUnique` | false | Removes owned Unique Skills from reincarnation skill list |
| `vanillaEP` | 100 | How much percentage of default EP value that vanilla mobs can be used for EP gain calculation |
