# `config/tensura/entity/projectile_config.toml`

<small>[Tensura: Reincarnated](../index.md) &rsaquo; [Configs](index.md)</small>

## Top level

| Option | Default | Range | Description |
|---|---|---|---|
| `spearDespawnTick` | 600 |  | The number of ticks that a spear, kunai or tensura arrow needs to be on ground to despawn. |
| `thrownItemDespawnTick` | 400 |  | The number of ticks that a thrown item (normally by Thrower) needs to be on ground to despawn. |
| `magicDespawnTick` | 200 |  | The number of ticks that a magic entity needs to despawn by default if not custom set. |
| `projectileDespawnTick` | 100 |  | The number of ticks that a magic projectile needs to despawn by default if not custom set. |
| `projectileDespawnRange` | -1 |  | How many blocks away from the shooter that a magic projectile needs to be to despawn.<br>Set to a value higher than 0 to enable this. |
