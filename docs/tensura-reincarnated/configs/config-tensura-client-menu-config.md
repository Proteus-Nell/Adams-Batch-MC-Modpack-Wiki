# `config/tensura/client/menu_config.toml`

<small>[Tensura: Reincarnated](../index.md) &rsaquo; [Configs](index.md)</small>

## Top level

| Option | Default | Range | Description |
|---|---|---|---|
| `modifyFov` | true |  | Should FOV be slightly modified (zoomed out) upon opening a menu |
| `fadeEffects` | false |  | Should menus have a fade-in-out effect upon opening and closing them<br>(it takes 10 ticks / half a second for the effect to end before you can do anything) |
| `scale` | 1 |  | The value by which to multiply the scale of every menu and its elements (Vanilla options also affect menu scale) |
| `blurStrength` | 0 |  | How much should the background be blurred; 0 - 5 |
| `autoAbilitySlot` | false |  | Should the ability slots/bars be automatically shown when opening ability GUIs |
