| `minScale` | 0.15 |  | The minimum Size Scale an entity can get. |

| `attackGain` | 0.5 |  | The amount of attack a non-player mob gains for every 10000 EP it gains. |
| `HPGain` | 1 |  | The amount of HP a non-player mob gains for every 10000 EP it gains. |
| `SHPGain` | 5 |  | The amount of SHP a non-player mob gains for every 10000 EP it gains. |
