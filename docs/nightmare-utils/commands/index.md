# Commands

<small>[Nightmare Utils](../index.md)</small>

`<value>` is a required argument, `[value]` is optional. The permission column shows who can run it by default.

## `/nightmareutils awakening`

| Syntax | Permission |
|---|---|
| `/nightmareutils awakening progress <player> <id> <amount>` | Operator (level 2) |
| `/nightmareutils awakening start <player> <id>` | Operator (level 2) |
| `/nightmareutils awakening status <player> <id>` | Operator (level 2) |
| `/nightmareutils awakening trigger <player> <id>` | Operator (level 2) |
