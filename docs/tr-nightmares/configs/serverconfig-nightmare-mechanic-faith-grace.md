## `[faith_and_grace]`

| Option | Default | Range | Description |
|---|---|---|---|
| `maxGods` | 3 | 0 to no limit | Maximum number of Gods/Faith leaders allowed in the world. Set to 0 to disable the limit. |
| `maxFollowersPerFaith` | 20 | 0 to no limit | Maximum number of non-God followers a single faith may have. Priests count toward this limit. Set to 0 to disable the limit. |
| `maxPriestsPerFaith` | 4 | 0 to no limit | Maximum number of Priests a single faith may have. Set to 0 to disable the limit. |
