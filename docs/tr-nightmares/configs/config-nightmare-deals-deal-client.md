# `config/nightmare/deals/deal_client.toml`

<small>[TR: Nightmares](../index.md) &rsaquo; [Configs](index.md)</small>

## Top level

| Option | Default | Range | Description |
|---|---|---|---|
| `dealsDirectory` | "nightmare/deals" |  | Directory where deal contract templates (.json) are stored. Relative to config/. |
| `maxContractTemplates` | 100 |  | Maximum number of contract templates to display in the Contract Book. |
| `showExpiryTimestamps` | true |  | Whether to show deal expiry timestamps in the Contract Book. |
| `showPartyNames` | true |  | Whether to show deal party names in the Contract Book. |
| `activeDealColor` | "55FF55" |  | Color for active deals in the UI (hex, without #). |
| `expiredDealColor` | "AAAAAA" |  | Color for expired/completed deals in the UI (hex, without #). |
| `brokenDealColor` | "FF5555" |  | Color for broken deals in the UI (hex, without #). |
