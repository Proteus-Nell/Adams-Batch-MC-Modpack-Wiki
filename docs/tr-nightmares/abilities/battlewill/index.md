# Battlewill

<small>[TR: Nightmares](../../index.md) &rsaquo; [Abilities](../index.md)</small>

Martial arts powered by aura (AP) instead of magicules.

| | Ability | Description |
|---|---|---|
|  | [Air Palm](air-palm.md) | Strike the air to launch a wide shockwave, splitting heavy Wind and Gravity damage across targets. |
|  | [Aura Armor](aura-armor.md) | While active, convert your Max Aura into bonus Attack Damage and Armor. |
|  | [Barrage Strike](barrage-strike.md) | Blink onto your target and unleash a rapid multi-hit combo. |
|  | [Battle Mode](battle-mode.md) | Lock onto the target in your sights. The lock breaks if they move too far, out-conceal your Presence Sense, or you release it. |
|  | [Gravity Hammer](gravity-hammer.md) | Crush the ground with gravity force, damaging and launching nearby grounded enemies upward. |
|  | [Maximum Will](maximum-will.md) | Hold to enter a counter stance. Incoming attacks can be dodged, then punished on release with heavy retaliatory damage. |
|  | [Night Strike](night-strike.md) | Warp behind your target for a devastating opener, apply Blood Mist, then activate again to detonate it. |
|  | [Oni Pyre](oni-pyre.md) | After charging, erupt pillars of flame beneath nearby enemies. |
|  | [Pressure Training](pressure-training.md) | Cycle damage types while sneaking, then endure that damage to train your resistances. |
|  | [Spiral Penetrator](spiral-penetrator.md) | Charge up power scales, then lunge through your target with a piercing strike. |
|  | [Vortex Punch](vortex-punch.md) | Drag your target in, then shatter them with a wind-boosted impact. Requires empty hands. |
