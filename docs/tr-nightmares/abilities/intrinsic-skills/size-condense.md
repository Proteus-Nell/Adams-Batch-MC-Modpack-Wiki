> An intrinsic Giant Clan and Dragon Race skill that condenses the user's body to a smaller combat form.

## Modes

| # | Mode |
|---|---|
| 1 | Normal Player Size |
| 2 | 75% Player Size |

## How it works

- Activated by pressing the skill key

### Attribute changes

| Attribute | Amount | Operation |
|---|---|---|
| scale | modifier amount | multiply total |
