> Spread the blessed rejuvenation of holy light among allies to bring them prosperity and health

## Costs

| When | Magicule (MP) | Aura (AP) |
|---|---|---|
| Always | 5,000 |  |

## How it works

- Charged or channelled by holding the skill key

## Obtaining

- Can be found in skill tomes
- Sold by dwarf traders (high basic tome)
- Sold by dwarf traders (high upgraded tome)
- Can appear in rare tomes in buried wizard towers
- Can appear in rare tomes in burnt wizard towers
- Can appear in rare tomes in frozen wizard towers
- Can appear in rare tomes in rotted wizard towers
- Can appear in rare tomes in ruined wizard towers

## Stats (config defaults)

Set in [`config/nightmare/ability/magic/holy.toml`](../../configs/config-nightmare-ability-magic-holy.md).

| Option | Default | Description |
|---|---|---|
| `Rejuvenate.castTime` | 10 | Cast time in seconds. |
| `Rejuvenate.magiculeCost` | 5,000 | Magicule Cost  per heal per target. |
| `Rejuvenate.spiritronCost` | 2 | Spiritron Cost per heal per target. |
| `Rejuvenate.healAmount` | 50 | Amount HP healed per second. |
| `Rejuvenate.range` | 6 | The block range of the spell unmastered. |
| `Rejuvenate.rangeMastered` | 10 | The block range of the spell mastered. |
