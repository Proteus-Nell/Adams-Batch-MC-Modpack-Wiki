> The Wedding Bells of Holy Matrimony fill the world, being close to an ally when surrounded by enemies makes the bells more powerful

## Costs

| When | Magicule (MP) | Aura (AP) |
|---|---|---|
| Always | 10,000 |  |

## How it works

- Triggers when the held key is released

## Obtaining

- Can be found in skill tomes
- Sold by dwarf traders (high basic tome)
- Sold by dwarf traders (high upgraded tome)
- Sold by dwarf traders (medium basic tome)
- Sold by dwarf traders (medium upgraded tome)
- Can appear in rare tomes in buried wizard towers
- Can appear in rare tomes in burnt wizard towers
- Can appear in rare tomes in frozen wizard towers
- Can appear in rare tomes in rotted wizard towers
- Can appear in rare tomes in ruined wizard towers
- Can appear in uncommon tomes in buried wizard towers
- Can appear in uncommon tomes in burnt wizard towers
- Can appear in uncommon tomes in frozen wizard towers
- Can appear in uncommon tomes in rotted wizard towers
- Can appear in uncommon tomes in ruined wizard towers

## Stats (config defaults)

Set in [`config/nightmare/ability/magic/holy.toml`](../../configs/config-nightmare-ability-magic-holy.md).

| Option | Default | Description |
|---|---|---|
| `WeddingBell.castTime` | 6 | Cast time in seconds. |
| `WeddingBell.magiculeCost` | 10,000 | Magicule Cost to cast. |
| `WeddingBell.spiritronCost` | 15 | Spiritron Cost to cast. |
| `WeddingBell.holyDamage` | 20 | The holy damage of the bell unmastered. |
| `WeddingBell.holyDamageMastered` | 40 | The holy damage of the bell mastered. |
| `WeddingBell.holyDamageBoost` | 15 | The holy damage boost amount with ally. |
| `WeddingBell.range` | 5 | The block range of the bell unmastered. |
| `WeddingBell.rangeMastered` | 7 | The block range of the bell mastered. |
| `WeddingBell.rangeBoost` | 3 | The block range amount with ally. |
| `WeddingBell.allyRange` | 7 | The block range for ally boost. |
