## Game rules

Change these with `/gamerule <name> <value>`.

| Game rule | Default | Description |
|---|---|---|
| `auto_evolve` | false |  |
| `EntityAwakening` | true | Allow non-player entities to awaken when awakening conditions are met. |
| `entityAwakeningMinEp` | 200,000 |  |
| `entityAwakeningSoulPointsRaw` | 10,000,000 |  |
| `giftofworld` | true | Enable Gift of the World related features. |
| `god_skills` | false | Enable God-class skill progression and acquisition checks. |
| `lose_unique_on_upgrade` | true | If enabled, prerequisite unique skills can be removed when evolving. |
| `maxDealMakerUsers` | 1 | Maximum number of players allowed to be Deal Maker users at once. |
| `nightmare_ultimates` | true | Enable Nightmare ultimate skill progression and acquisition checks. |
| `nightmareSoulTraits` | true | Enable Nightmare soul trait assignment and updates. |
| `nightmareSoulType` | true | Enable Nightmare soul type assignment and updates. |
| `PredGlutGourmtGetFoodChain` | true | Allow configured skills to grant Food Chain automatically. |
| `trulygodclass` | false | Limit Truly God Class ownership based on server rules. |
| `TrulyNameless` | false |  |
| `UltimateSlots` | false |  |
| `uniquetruedragons` | true | Allow only one owner per True Dragon seed until reset. |
