# Commands

<small>[Relics](../index.md)</small>

`<value>` is a required argument, `[value]` is optional. The permission column shows who can run it by default.

## `/relics ability`

| Syntax | Permission |
|---|---|
| `/relics ability points <action> <ability> <points>` | Operator (level 2) |
| `/relics ability quality <action> <ability> <stat> <quality>` | Operator (level 2) |
| `/relics ability randomize <ability> <stat>` | Operator (level 2) |
| `/relics ability value <action> <ability> <stat> <value>` | Operator (level 2) |
