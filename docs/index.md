# Adam's Batch Modpack Wiki

A wiki for the mods in **Adam's Batch**, a Minecraft **1.21.1 NeoForge** modpack built around *That Time I Got Reincarnated as a Slime* (Tensura) and its addons.

Every skill, race, item, mob, effect, enchantment, config option and command on this site was read straight from the mod files the pack ships, so names, numbers and defaults match the versions you are playing. Where the pack changes a default, the page says so in a **Pack note**.

## How the wiki is organised

Each mod has its own section, split into the same kinds of pages the [Tensura: Reincarnated wiki](https://tensura.wiki.gg/) uses:

| Section | What you'll find |
|---|---|
| **Abilities** | Skills (Ultimate, Unique, Extra, Common, Intrinsic, Resistance), Magic and Battlewill, each with modes, costs, how to get it and its config values |
| **Races** | Stats, evolution trees and requirements, intrinsic and learnable skills |
| **Items** and **Blocks** | Recipes, loot sources, relic abilities, tooltips |
| **Mobs** | Health, damage, EP, innate skills, spawns and drops |
| **Effects** and **Enchantments** | What they do and what applies them |
| **Biomes**, **Dimensions**, **Structures** | World generation added by the mod |
| **Mechanics** | Guides to each mod's systems |
| **Commands** and **Configs** | Every command and every config option with its default |

Use the search bar (top right) to jump straight to anything by name.
