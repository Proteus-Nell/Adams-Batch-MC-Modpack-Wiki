# Mechanics

Relics are wearable or usable items with **abilities** that grow as you use them.

## Finding relics

Relics generate in loot chests. Each relic page says which kinds of chests (for example "chests in desert biomes" or "any Nether chest") can contain it.

## Levelling

- A relic gains **experience** as you use its abilities. Each relic page lists what earns experience.
- When a relic levels up it earns points you can spend to upgrade its abilities. Most relics go up to level 10 or more; the exact cost is on each page.
- Some abilities unlock only when the relic reaches a certain level.

## Abilities and stats

Each ability has one or more **stats**. A new relic rolls a random starting value for every stat, inside the range shown on its page (for example *2-4*). Every upgrade level raises the stat by the listed amount (for example *+25% of base per level*), up to the value in the **At max level** column. Abilities are either **passive** or **active** (bound to the ability key).

## Commands

Operators can adjust a relic's experience, ability points, stat quality and values with `/relics ...` (see [Commands](@/relics/commands/index.md)).
