# Gateways to Eternity: what things do

Written from the mod's code (Gateways to Eternity 5.1.0).

## gateways:gate_pearl
Opens a Gateway. Every Gate Pearl is bound to one gateway (see the [gateway list](@/gateways-to-eternity/gateways/index.md)), and its name and tooltip show which one, with its waves and rewards.

**Right-click a block** to open the gateway on top of it. The pearl is used up (not in creative). It fails if the gateway's own conditions aren't met, if another gateway is too close, or if there isn't enough room above the block (it checks up to 4 blocks up). Once open, the gateway spawns its waves of mobs; beat every wave to get the rewards.
